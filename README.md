# Owen Visser — GitHub Pages website

Upload the **contents of this folder** (not the containing folder) to the root of `owenvisser.github.io`.

- `index.html` — concise homepage with About Me, CV/profiles, and 3 exploration cards.
- `academic.html` — previous academic/CV sections.
- `software.html` — packages, projects, tutorials, and skills.
- `travel.html` — starting photography page.
- `css/site.css` — shared stylesheet used by all four pages.
- `img/`, `files/`, etc. — original assets, preserved in their original paths.
- `index-original.html` — backup of the site before the redesign (kept for reference).

All navigation and asset links are relative and work from the GitHub Pages repository root.
The Teaching card is intentionally hidden until content is available.
